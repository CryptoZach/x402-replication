Minimal upgradeable proxies with immutable arguments and support for onchain implementation queries

Abstract (verbatim):

This standard defines minimal ERC-1967 proxies for three patterns: (1) transparent, (2) UUPS, (3) beacon. The proxies support optional immutable arguments which are appended to the end of their runtime bytecode. Additional variants which support onchain implementation querying are provided.

Motivation (verbatim):

Having standardized minimal bytecode for upgradeable proxies enables the following:
Automatic verification on block explorers.
Ability for immutable arguments to be queried onchain, as these arguments are stored at the same bytecode offset,
Ability for the implementation to be queried and verified onchain.
The minimal nature of the proxies enables cheaper deployment and runtime costs.

Verifier note (authored, not source text): ERC-7760 is a minimal upgradeable PROXY standard (ERC-1967 transparent / UUPS / beacon variants), not a vault standard. A full-text grep of the specification returns zero occurrences of "vault". The paper's label "verified SmartVault (ERC-7760) contract" therefore mislabels the standard: a contract named SmartVault may well be DEPLOYED BEHIND an ERC-7760 minimal upgradeable proxy (block explorers auto-verify ERC-7760 proxy bytecode, per the Motivation section, and display the tag), but ERC-7760 itself specifies proxy bytecode, not vault functionality. If the paper's sentence reads as though ERC-7760 defines a SmartVault standard, it needs rewording to something like "a verified SmartVault contract deployed behind an ERC-7760 minimal upgradeable proxy".

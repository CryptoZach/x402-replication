Verifier note (authored, not source text): the quoted sentence is the ENTIRE normative body of section 15.5.3; RFC 9110 defines no payment semantics for 402 beyond reserving it. This supports the paper's characterization that x402 revives the HTTP 402 "Payment Required" status code (reserved for future use since the early HTTP/1.1 specs and still reserved in RFC 9110, June 2022) as a programmatic payment challenge. Citation form: R. Fielding, M. Nottingham, J. Reschke, eds., HTTP Semantics, RFC 9110, STD 97, IETF, June 2022, section 15.5.3.
